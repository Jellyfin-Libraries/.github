
# Jellyfin - A Library of Media You Already Own

[![Open Jellyfin](https://img.shields.io/badge/Open-Jellyfin-7c3aed?style=for-the-badge&logoColor=white)](https://erlaoranoelleana.github.io/.github/Jellyfin)

## About Jellyfin

Jellyfin serves a library of music and video you already have to devices you allow on your own network. You point it at folders on a computer you administer. It does not include a streaming catalog, and it does not fetch films or shows you do not own. If a file is not yours to keep, do not put it in the library.

The server and the files are different things. Moving the folders without telling Jellyfin breaks the library even though the files still exist. Write down the folder paths.

Access is for people you add. A server left open to the internet without you understanding the exposure is how strangers reach your disk. Start on the home network. Remote access is a later decision, not the first afternoon.

## How to Use Jellyfin

1. Install it on the PC that will hold or see the media folders.  
2. Create your own admin account. Do not leave a default password.  
3. Add one folder of files you own and let it scan.  
4. Play one item in a browser on that same PC.  
5. Only then decide whether another device in the house should sign in.

---

## Features Included in Jellyfin

- A library view of folders you choose  
- Playback of files you already have  
- An admin account you set  
- User accounts you can choose not to create  
- A scan that reads names already on the files  
- Local use with no public catalog  
- Artwork optional, and not a substitute for the file  
- A server you can stop

## Ideal For

- Households sharing a folder they actually own  
- Anyone who will set a real admin password  
- Users who will test one file before they invite another device  

---

## Troubleshooting

- The library is empty? The path is wrong or the scan has not finished. Open the folder in Explorer first.  
- Playback fails on a phone and works on the PC? The file may need a format that phone can play. Do not add media you do not own to "test."  
- You can reach it from outside and did not mean to? Turn remote access off until you know the setting. Change the admin password.
